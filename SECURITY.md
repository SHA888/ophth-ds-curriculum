# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project (e.g., accidental exposure of PHI, secret keys, or a denial‑of‑service vector), please **do not** open a public issue. Instead, disclose it privately by emailing the maintainers at `security@ophth-ds-curriculum.org`.

We will acknowledge receipt of the report within 48 hours and work with you to resolve the issue as quickly as possible. Once a fix is available, we will publish a security advisory and release a patched version.

## Responsible Disclosure

We follow a responsible disclosure process:
1. **Private report** – email the address above.
2. **Verification** – maintainers confirm the issue and assess impact.
3. **Fix** – a patch is prepared and tested.
4. **Advisory** – a CVE (if applicable) and a GitHub security advisory are published.
5. **Release** – a new version containing the fix is released.

## No Sensitive Data in the Repository

All data used in the curriculum are public‑domain or have explicit usage licenses. No patient‑identifiable information (PHI) or private keys are ever committed. If you spot accidental inclusion of such data, please report it immediately via the above channel.
