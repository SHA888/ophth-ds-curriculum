# Phase 0 Assessment Checklist

Binary checklist. All items must pass.

- [ ] Learner has cloned the repository and can navigate the directory structure.
- [ ] Learner has completed all weekly modules in `phases/00-foundation/intro/` (4 weeks).
- [ ] Learner has completed all weekly modules in `phases/00-foundation/basic/` (16 weeks).
- [ ] Learner has completed all weekly modules in `phases/00-foundation/intermediate/` (20 weeks).
- [ ] Learner can explain the difference between prediction and inference (Intermediate tier outcome).
- [ ] Learner has submitted a capstone project (Basic: Quarto report reproducing an anesthesia paper; Intermediate: Python pipeline using VitalDB/eICU).
- [ ] All exercises are committed to a personal GitHub repository linked from the learner's record.
- [ ] No PHI or private data is present in any submitted artifact.

**Pass condition:** All boxes checked. Proceed to Phase 1.
